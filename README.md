# Django LMS (Learning Management System)

## Описание проекта

Проект представляет собой учебную платформу с возможностью управления курсами, уроками, пользователями и платежами. Реализованы подписки, валидация ссылок, JWT-авторизация, фильтрация, пагинация, Stripe-интеграция и Celery для асинхронных задач.

---

## Технологии

- Python 3.11+
- Django
- Django REST Framework
- djoser (для регистрации/авторизации)
- SimpleJWT (JWT-токены)
- PostgreSQL
- Celery + Redis
- Stripe
- drf-yasg (Swagger)
- Pytest / unittest

---

## Основной функционал

### Пользователи

- Регистрация по email.
- Поля модели:
  - `email`
  - `телефон`
  - `город`
  - `аватар`
- Поддержка JWT-авторизации.
- CRUD для пользователей (доступен только самому пользователю или админу).

---

### 🎓 Курсы

- Поля:
  - `название`
  - `описание`
  - `превью (изображение)`
- Один курс содержит множество уроков.
- В API:
  - **Количество уроков** выводится через `SerializerMethodField`.
  - **Уроки курса** отображаются вложенным сериализатором.
- CRUD реализован через `ViewSet`.

---

### Уроки

- Поля:
  - `название`
  - `описание`
  - `ссылка на видео` (валидируется — **только youtube.com**)
  - `превью`
- CRUD реализован на `GenericAPIView`.
- Валидация ссылок реализована через файл `validators.py`.

---

### Платежи

- Поля:
  - `пользователь`
  - `оплаченный курс (FK)`
  - `оплаченный урок (FK)`
  - `дата оплаты`
  - `сумма оплаты`
  - `способ оплаты`: `наличные` / `перевод`
- Реализована **фильтрация и сортировка**:
  - По дате (сортировка)
  - По курсу или уроку
  - По способу оплаты

---

### Подписки

- Пользователь может подписаться на курс.
- Модель содержит:
  - `пользователь`
  - `курс`
- Эндпоинты:
  - Подписка на курс
  - Отписка от курса
- В API курсов добавлен флаг — подписан ли текущий пользователь на курс.

## Установка и запуск

```bash
git clone https://github.com/yourname/lms-project.git
cd lms-project

# создаем и активируем виртуальное окружение
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# установка зависимостей
pip install -r requirements.txt

# настройка базы данных и миграции
python manage.py migrate

# создание суперпользователя
python manage.py createsuperuser

# запуск сервера
python manage.py runserver

# Запуск Redis-сервера (если установлен локально)
redis-server

# Запуск Celery worker
celery -A lms_project worker -l info

# Запуск планировщика периодических задач
celery -A lms_project beat -l info
